# Milan Matrimony — Phase 1 Final

Milan is intentionally designed as a **mobile-app-first experience**. On desktop browsers, the same compact app viewport is centered rather than expanding into a traditional website.

## Included
- App shell with persistent header and bottom navigation
- Home/dashboard
- Discover/search/filter bottom sheet
- Profile
- Sign in
- Multi-step sign up
- Shared reusable components
- Premium warm/editorial visual language
- Matrimony-oriented UI, not swipe/dating UI
- Responsive mobile viewport
- API environment placeholder for later integration

## Run
```bash
npm install
npm run dev
```

Production:
```bash
npm run build
```

## Cumulative rule
This is the complete Phase 1 baseline. Every future phase must preserve this build and add to it, producing a complete cumulative final snapshot.
